# نظام الحجز الآلي بالساعة ومنع تعارض المواعيد — عيادة أوراس لطب الأسنان

نظام متكامل لإدارة حجوزات المواعيد **بالساعة** عبر موقع عيادة أوراس لطب الأسنان ([orasdentalclinic.com](https://orasdentalclinic.com)) مع منع تعارض المواعيد والتكامل الآلي مع جدول Google Sheets وتقويم Google Calendar.

---

## 🌟 مميزات النظام

1. **الحجز بالساعة (12 ساعة متواصلة):** يعمل النظام يومياً من **8:00 صباحاً حتى 8:00 مساءً** — ساعات الحجز: `08:00 ، 09:00 ، … ، 19:00` وكل ساعة فترة مستقلة مدتها ساعة.
2. **رسالة «متاح / غير متاح» بعد الضغط على زر الحجز:** لا فحص مباشر أثناء تعبئة النموذج — عند الضغط على «احجز الآن» يتحقق النظام من التوفر ويظهر للزائر على الفور:
   - ✅ **متاح** → يُسجَّل الحجز آلياً في Google Sheets + Google Calendar وتظهر رسالة نجاح.
   - ❌ **غير متاح** (ساعة ممتلئة / الجمعة عطلة / ساعة منقضية) → مع اقتراح 3 مواعيد بديلة قابلة للنقر تحجز تلقائياً.
3. **فصل زر الحجز الآلي عن زر واتساب:** زرّان مستقلان تماماً:
   - **«احجز الآن — تأكيد فوري»**: المسار الآلي (فحص توفر + تسجيل + تقويم).
   - **«حجز عبر واتساب»**: يفتح واتساب برسالة منسقة مباشرة — بدون فحص توفر ولا تسجيل آلي.
4. **منع تعارض المواعيد (Conflict Prevention):** قفل متزامن عبر `LockService` + سعة لكل ساعة (`MAX_PER_HOUR = 4`).
5. **منع الأخطاء الزمنية:** رفض التواريخ الماضية، وأيام الجمعة، وساعات اليوم التي بدأت أو انتهت (حسب توقيت العيادة `Africa/Khartoum`).
6. **تكامل مع Google Calendar:** إنشاء موعد مدته ساعة واحدة في التقويم تلقائياً.

## 📋 خطوات الإعداد والتثبيت

### 1. إنشاء جدول بيانات Google Sheets
1. توجّه إلى [Google Sheets](https://sheets.new) وأنشئ جدول بيانات جديداً.
2. ستقوم الأداة البرمجية تلقائياً بإنشاء ورقة `حجوزات` بالترويسات المناسبة عند أول تشغيل.

### 2. إضافة كود Google Apps Script
1. من قائمة جدول البيانات، اختر: **الإضافات (Extensions)** > **تطبيقات Apps Script**.
2. امسح أي كود افتراضي، والصق محتوى الملف `booking/Code.gs`.
3. يمكنك تعديل الإعدادات في أعلى الملف داخل كائن `CONFIG`:
   - `OPEN_HOUR`: بداية الدوام (افتراضياً `8` أي 8:00 صباحاً).
   - `CLOSE_HOUR`: نهاية الدوام (افتراضياً `20` أي 8:00 مساءً — آخر ساعة حجز 19:00).
   - `MAX_PER_HOUR`: الحد الأقصى للمرضى في الساعة الواحدة (افتراضياً `4`).
   - `TIMEZONE`: المنطقة الزمنية للعيادة (افتراضياً `'Africa/Khartoum'`).
   - `NOTIFICATION_EMAIL`: بريد إلكتروني اختياري لاستقبال تنبيهات فورية بكل حجز.

### 3. نشر المشروع كتطبيق ويب (Web App)
1. في محرر Apps Script، اضغط **نشر (Deploy)** > **نشر جديد (New deployment)**.
2. اختر نوع النشر: **تطبيق ويب (Web app)**.
3. اضبط الخيارات:
   - **تنفيذ التطبيق باسم (Execute as):** `أنا (حسابك - Me)`
   - **من يملك حق الوصول (Who has access):** `أي شخص (Anyone - Anonymous)`
4. اضغط **نشر (Deploy)** وامنح الصلاحيات المطلوبة (Sheets, Calendar, Email).

> ⚠️ **مهم بعد أي تعديل على `Code.gs`:** اضغط **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** حتى يعمل الموقع بالمنطق الجديد (تحديث الكود وحده لا يكفي).

### 4. ربط الرابط مع واجهة الموقع
الرابط مثبّت مسبقاً في السطر الأول من `oras-booking.js`:
```javascript
var ENDPOINT = 'https://script.google.com/macros/s/…/exec';
```
عند إعادة النشر من جديد يتغير الرابط — انسخ الرابط الجديد وضعه هنا.

## 🧪 اختبار النظام البرمجي

من داخل محرر Apps Script اختر الدالة `testBooking` واضغط **تشغيل (Run)**، ثم راجع سجل التنفيذ:
- جلب بيانات التوفر (`doGet`) مع قائمة الساعات الـ12.
- نجاح حجز ساعة `10:00` في يوم قادم.
- رفض حجز يوم الجمعة مع تقديم بدائل بالساعة.
- رفض تاريخ ماضٍ مع تقديم بدائل.

اختبر الواجهة كاملة محلياً: افتح `index.html`، املأ الاسم والهاتف والتاريخ والساعة، واضغط «احجز الآن» — ستظهر رسالة التوفر فوق زر الحجز.

## 📊 هيكل بيانات ورقة الحجوزات

| العمود | العنوان | الوصف |
|---|---|---|
| A | الطابع الزمني | وقت تسجيل الحجز |
| B | الاسم الكامل | اسم المريض |
| C | رقم الهاتف | هاتف المريض |
| D | الخدمة المطلوبة | الخدمة المختارة من القائمة |
| E | تاريخ الحجز | التاريخ بصيغة YYYY-MM-DD |
| F | الساعة | نطاق الساعة المحجوزة، مثال: `10:00 - 11:00` |
| G | ملاحظات | ملاحظات إضافية من المريض |
| H | المصدر | موقع عيادة أوراس |
| I | الحالة | مؤكد / ملغي |
| J | معرّف حدث التقويم | ربط الحجز بحدث Google Calendar |

> الأعمدة القديمة التي تحمل عنوان «الفترة» بقيم (صباحية/مسائية) تُقرأ كسجل تاريخي ولا تتقاطع مع مفاتيح الساعات الجديدة.

## 🔌 واجهة البرمجة (Web App API)

### `GET ?action=availability`
```json
{
  "ok": true,
  "mode": "hourly",
  "max": 4,
  "openHour": "08:00",
  "closeHour": "20:00",
  "hours": ["08:00","09:00","…","19:00"],
  "today": "2026-09-01",
  "nowHour": 14,
  "closed": [],
  "taken": { "2026-09-01|10:00": 2 },
  "timestamp": 1790000000000
}
```

### `POST` — تسجيل حجز
```json
{ "name": "…", "phone": "…", "service": "…", "date": "2026-09-01", "hour": "10:00", "notes": "…", "source": "موقع عيادة أوراس" }
```
الاستجابة إما `{ "ok": true, … }` أو `{ "ok": false, "conflict": true, "reason": "…", "alternatives": [ { "date": "…", "hour": "11:00", "label": "الثلاثاء 2026-09-01 — 11:00 صباحاً" } ] }`
