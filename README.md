# موقع عيادة أوراس لطب الأسنان

موقع ثابت (صفحة واحدة) + لوحة تحكم Sanity لإدارة المحتوى بدون لمس الكود.

```
oras/
├── index.html          ← الموقع (يُنشر على GitHub Pages)
├── education.html      ← صفحة «أوراس التعليمية» (قسم المرضى + قسم الأطباء)
├── oras-transition.js  ← حركة الانتقال بين الصفحات (الدائرة الذهبية + السنّ)
├── CNAME               ← orasdentalclinic.com
├── booking/            ← سكربت Google Apps Script (الحجز الآلي + استقبال التقييمات)
└── studio/             ← لوحة التحكم (Sanity Studio)
    ├── sanity.config.js
    ├── sanity.cli.js
    ├── schemaTypes/    ← تعريف الحقول
    └── scripts/seed.mjs ← تعبئة المحتوى الافتراضي
```

## كيف يعمل الربط

الموقع صفحة HTML واحدة تحتوي على محتوى افتراضي مكتوب بداخلها. عند فتحها تطلب
المحتوى من Sanity وتستبدل النصوص والصور. **إذا فشل الاتصال أو لم يُضبط المعرف،
يبقى المحتوى الافتراضي ظاهراً** — الموقع لا ينكسر أبداً.

```
لوحة التحكم  ──نشر──▶  Sanity  ──استعلام GROQ──▶  index.html
```

## خطوات التشغيل

### 1) إنشاء مشروع Sanity

```bash
cd studio
npm install
npx sanity login          # سجّل دخولك (Google / GitHub / بريد)
```

> المشروع منشأ بالفعل — معرفه **`upxb9w10`**. لا حاجة لـ `sanity init`.

### 2) ربط اللوحة بالمشروع

```bash
cp .env.example .env
```

الملف يجب أن يحتوي على:

```
SANITY_STUDIO_PROJECT_ID=upxb9w10
SANITY_STUDIO_DATASET=production
```

> `.env` غير مرفوع على Git (لأسباب أمنية) — أنشئه بعد كل استنساخ للمستودع.

### 3) ✅ ربط الموقع بالمشروع — تم مسبقاً

المعرف **`upxb9w10`** مضبوط في `index.html` وفي `studio/sanity.config.js` و`sanity.cli.js`:

```js
window.ORAS_SANITY_CONFIG = { projectId: 'upxb9w10', dataset: 'production' };
```

### 4) جعل البيانات قابلة للقراءة علناً

الموقع يقرأ بدون توكن، لذا يجب أن يكون الـ dataset عاماً:

**sanity.io/manage → مشروعك → Datasets → production → Visibility → Public**

> هذا آمن: يجعل المحتوى المنشور فقط قابلاً للقراءة — لا أحد يستطيع التعديل
> بدون تسجيل دخول.

### 5) السماح لنطاق موقعك (CORS)

**sanity.io/manage → API → CORS origins → Add origin**

أضف (بدون تفعيل `Allow credentials`):

| النطاق | الغرض |
|---|---|
| `https://orasdentalclinic.com` | الموقع المباشر |
| `https://www.orasdentalclinic.com` | نسخة www |
| `https://orasdentalclinc-del.github.io` | نطاق GitHub Pages |
| `http://localhost:3333` | التطوير المحلي |

### 6) تشغيل اللوحة

```bash
cd studio
npm run dev        # http://localhost:3333
```

### 7) تعبئة المحتوى الافتراضي (اختياري)

بدل كتابة كل شيء يدوياً، انقل محتوى الموقع الحالي إلى اللوحة دفعة واحدة.
أنشئ توكن **Editor** من: sanity.io/manage → API → Tokens

```bash
SANITY_WRITE_TOKEN=توكنك npm run seed
```

### 8) نشر اللوحة على الإنترنت

```bash
npm run deploy
```

تختار اسماً وتصبح اللوحة على `https://الاسم.sanity.studio` — يفتحها أي شخص
تدعوه من **sanity.io/manage → Members → Invite**.

## أقسام اللوحة

| القسم | النوع | ماذا يتحكم |
|---|---|---|
| ⚙️ إعدادات الموقع | `siteSettings` | الاسم، الواجهة، من نحن، الأرقام، العناوين، الهاتف، واتساب، الخريطة، الدوام، **أسئلة الاستبيان** |
| 🦷 الخدمات | `service` | بطاقات الخدمات + قائمة الخدمات في نموذج الحجز |
| ✨ الحالات | `caseStudy` | صور قبل/بعد بالفاصل المتحرك |
| 🖼️ نشاط العيادة | `galleryItem` | قسم «نشاط العيادة»: صورة غلاف + **ألبوم صور (أكثر من صورة)** + **نص تعريفي** يظهر أعلى الألبوم |
| 👩‍⚕️ الأطباء | `doctor` | بطاقات الفريق الطبي |
| ⭐ آراء المرضى | `review` | التقييمات والتعليقات — اعتمدها لتظهر على الموقع |
| 🤝 الشراكات | `partner` | شعارات وتفاصيل الشركاء |

**الترتيب:** كل عنصر فيه حقل «الترتيب» — الرقم الأصغر يظهر أولاً.

## 🖼️ نشاط العيادة — ألبوم الصور

كل نشاط في هذا القسم صار له **ألبوم** بدل صورة واحدة:

| الحقل في اللوحة | ماذا يفعل |
|---|---|
| اسم النشاط | يظهر على البطاقة في القسم، وكترويسة لنافذة الألبوم |
| النص التعريفي بالنشاط | يظهر **أعلى صور الألبوم** داخل النافذة |
| صورة الغلاف | الصورة داخل شبكة القسم (اختيارية — تُستخدم أول صورة من الألبوم إن تُركت فارغة) |
| ألبوم الصور | **أكثر من صورة** للنشاط نفسه، ولكل صورة تعليق اختياري يظهر أسفلها |

**تجربة الزائر:** يضغط على أي نشاط ← تفتح نافذة الألبوم **فوق الموقع مع تأثير ضبابي
(Blur) في الخلف**، فيقرأ النص التعريفي ثم يتصفح الصور بالأسهم أو الصور المصغّرة،
ويكبر أي صورة بزر التكبير.

- يظهر على البطاقة عدّاد **«N صور»** متى كان للنشاط أكثر من صورة.
- النشاط الذي بلا أي صورة (لا غلاف ولا ألبوم) لا تظهر بطاقته في الموقع،
  واللوحة تنبّهك برسالة: «أضف صورة الغلاف أو صورة واحدة على الأقل داخل ألبوم الصور».
- `npm run check` يخبرك كم نشاطاً له ألبوم وكم نشاطاً له نص تعريفي.

## ⭐ التقييمات وآراء المرضى — كيف تعمل؟

قسم «آراء المرضى» في الموقع يعمل مع اللوحة كالتالي:

1. **الزائر** يضغط «أضف تقييمك» فيحدد نجوم (1–5)، ويكتب اسمه (مطلوب) وتعليقه،
   ويجيب على **استبيان من 5 أسئلة**.
2. **عند الإرسال** يُرسل التقييم مباشرة إلى **لوحة تحكم Sanity** عبر نفس سكربت
   Google Apps Script الخاص بالحجز (`booking/Code.gs`) بدلاً من واتساب، ويُحفظ
   بحالة **«⏳ قيد المراجعة»** (التخزين الوحيد هو Sanity — بدون Google Sheet).
3. **أنت** تفتح **⭐ آراء المرضى** من اللوحة، تراجع التقييم ثم تضع الحالة
   **«✅ معتمد»** وتضغط **Publish** — فيظهر فوراً على الموقع ويُحدَّث متوسط
   النجوم وعدد التقييمات تلقائياً.

> **الواجهة:** يستخدم الموقع نفس رابط سكربت الحجز عبر `window.ORAS_REVIEW_ENDPOINT`
> (يُشتق تلقائياً من `window.ORAS_BOOKING_ENDPOINT`). خطوات تفعيل التوكن والربط:
> **[booking/README.md](booking/README.md)**.

**تعديل أسئلة الاستبيان:** ⚙️ إعدادات الموقع → مجموعة **«استبيان الزوار»** —
اكتب حتى 5 أسئلة واضغط Publish، فتتغير الأسئلة داخل نافذة التقييم في الموقع مباشرة.
(إن تُركت فارغة تُستخدم الأسئلة الافتراضية).

## 🎓 أوراس التعليمية — الصفحة التعليمية والانتقال السينمائي

الصفحة `education.html` هي **«أوراس التعليمية»** وتضم قسمين:

- **قسم مرضى أوراس** (`#patients`): ٦ بطاقات إرشادية للعناية اليومية بالأسنان، وما بعد
  التبييض والزراعة والتقويم، وعناية أسنان الأطفال، وعلامات التحذير التي تستدعي الزيارة الفورية.
- **قسم أطباء الأسنان** (`#dentists`): برامج التدريب السريري، ورش العمل المهارية،
  التحديثات العلمية، وفرص التعاون — مع زر «سجّل اهتمامك» عبر واتساب.

**الانتقال السينمائي (`oras-transition.js`):** كل رابط يحمل الخاصية `data-pt` لا يفتح
الصفحة مباشرة، بل يعرض دائرة ذهبية تتوسّع من المركز حتى تملأ الشاشة وسنّ يخرج من
منتصفها، ثم تُفتح الصفحة الجديدة وينعكس الأثر: يعود السنّ داخل الدائرة وتنكمش
الدائرة كاشفةً المحتوى. الحركة تحترم إعداد «تقليل الحركة» لدى المستخدم.

```
<a href="education.html" data-pt>أوراس التعليمية</a>   ← أي رابط بهذه الصيغة يحصل على الحركة
```

أزرار الصفحة موجودة في: قائمة التنقّل، الواجهة الرئيسية، والتذييل — ويمكن اختبار
منطق الحركة محلياً بـ `node test-transition.js`.

## 🔗 أزرار الاتصال وواتساب

- كل أيقونات وأزرار **واتساب** (العائم + التذييل + بطاقة الحجز + زر «حجز عبر واتساب») تستخدم الرقم
  المضبوط في إعدادات الموقع بصيغة `wa.me` — وتعمل بالنقر مباشرة.
- كل أزرار **الاتصال المباشر** تستخدم بروتوكول `tel:` (زر العائم الذهبي +
  بطاقة «اتصال مباشر» أعلى الصفحة + رقم التذييل) — تفتح تطبيق الاتصال فوراً.
- تغيير الرقم يتم من مكان واحد: إعدادات الموقع → الاتصال (حقل «رقم الهاتف»
  و«رقم واتساب») — وينعكس على كل الأزرار.

**رقم واتساب:** يُكتب بالصيغة الدولية بدون `+` وبدون مسافات — `249912345678`.

## 🕐 نظام الحجز بالساعة

نظام الحجز يعمل **بالساعة** — دوام متواصل 12 ساعة يومياً من **8:00 صباحاً حتى 8:00 مساءً**:

- الزائر يختار التاريخ والساعة (12 ساعة حجز: `08:00` حتى `19:00`) ثم يضغط
  **«احجز الآن — تأكيد فوري»**، فتظهر رسالة **«متاح ✅»** أو **«غير متاح ❌»**
  (مع 3 مواعيد بديلة قابلة للنقر) — الفحص يبدأ فقط بعد الضغط على الزر.
- إذا كان الموعد متاحاً يُسجَّل الحجز آلياً في **Google Sheets + Google Calendar**
  (سعة كل ساعة `MAX_PER_HOUR = 4` — انظر `booking/README.md`).
- **زر «حجز عبر واتساب» منفصل تماماً** عن الحجز الآلي: يفتح واتساب برسالة منسقة
  مباشرة بدون فحص توفر ولا تسجيل — للمستعجلين أو عند تعذر الاتصال.
- تفاصيل الخادم والإعداد: **[booking/README.md](booking/README.md)**.

## 📊 إحصاءات الزوار (GoatCounter)

الموقع جاهز للعمل مع **GoatCounter** — مجاني، بدون كوكيز، ولا يبطّئ الموقع.
كل الكود في **`oras-analytics.js`**، والإعداد في **سطر واحد** أسفل `index.html`.

> ⚠️ **مهم:** الإحصاء يبدأ من لحظة التفعيل. أي زيارات سابقة **لم تُسجَّل** — لأن السكربت
> لم يكن موجوداً في الموقع من قبل.

### 1) إنشاء حسابك (دقيقتان)

1. افتح **https://www.goatcounter.com/signup** وسجّل بريداً وكلمة مرور.
2. عند إضافة الموقع اكتب في **Domain** النطاق: `orasdentalclinic.com`
3. **Site code** — الموقع جاهز بالكود `oras-dental`، أي الرابط:
   `https://oras-dental.goatcounter.com`
   (لو اخترت كوداً مختلفاً، غيّره في `index.html` — انظر الخطوة 2)
4. افتح الرابط — تظهر لوحة الإحصاء (فارغة حتى الآن).

### 2) ربط الموقع (الخطوة الوحيدة المطلوبة منك)

في `index.html` — أسفل الصفحة، غيّر هذا السطر:

```js
window.ORAS_GOATCOUNTER = {
  code: 'oras-dental',          // ← كود موقعك (الجزء الأول من MYCODE.goatcounter.com)
  showVisitorCounter: false,
  trackLocal: false
};
```

ثم ارفع التغيير (commit + push) — **انتهى الأمر**. خلال دقائق تبدأ الأرقام بالظهور في لوحتك.

> اترك `code: ''` فارغاً ليبقى الإحصاء معطلاً تماماً: لا يُرسل أي طلب ولا يتأثر الموقع.
> زيارات `localhost` لا تُحتسب تلقائياً حتى لا تتلوّث أرقامك الحقيقية.

### 3) أين ترى عدد الزوار؟

**أ) اللوحة (الأسهل):** افتح `https://oras-dental.goatcounter.com`

| الرقم | معناه |
|---|---|
| **Views** | عدد مرات فتح الصفحة |
| **Visitors** | عدد الزوار الفريدين (من تريد معرفته) |

ومن القائمة الجانبية: **Pages** (أي الأقسام أكثر زيارة)، **Referrers** (من وين جاؤوا)،
**Countries**، **Browsers**.

**ب) من الطرفية (API)** — أنشئ توكن من: لوحتك → **Settings → API** → *Add new token* (صلاحيات read):

```bash
# عدد الزوار لكل يوم خلال آخر شهر
curl -s 'https://oras-dental.goatcounter.com/api/v0/stats/hits?start=2026-09-01&end=2026-09-30&daily=1' \
  -H "Authorization: Bearer $GOAT_TOKEN"
```

```bash
# إجمالي الزوار للفترة كلها
curl -s 'https://oras-dental.goatcounter.com/api/v0/stats/total?start=2026-09-01&end=2026-09-30' \
  -H "Authorization: Bearer $GOAT_TOKEN"
```

**ج) رقم ظاهر داخل الموقع (اختياري):** اجعل `showVisitorCounter: true` ثم فعّل من
لوحتك: **Settings → site → ✅ Allow adding visitor counts on your website** (مقفول افتراضياً).
فيظهر رقم الزوار صغيراً في التذييل. ملاحظة: الأرقام تُخبَّأ حتى **4 ساعات** في GoatCounter.

### 4) ماذا يُحسب تلقائياً؟

| الحدث في اللوحة | متى يُرسل |
|---|---|
| `booking_submit` | ضغط زر «احجز الآن — تأكيد فوري» (مع الخدمة والتاريخ والساعة) |
| `booking_confirmed` | حجز تأكد فعلاً على الخادم ✅ — **أهم رقم لقياس نجاح الموقع** |
| `whatsapp_click` | أي زر واتساب (الزر العائم، التذييل، بطاقة الحجز، بعد الحجز) مع رقم الوجهة |
| `call_click` | أي زر اتصال مباشر `tel:` مع الرقم |
| `review_submitted` | إرسال تقييم من نافذة «آراء المرضى» مع عدد النجوم |
| `path_change` | تنقّل الزائر بين أقسام الصفحة الواحدة |

تظهر هذه في لوحتك تحت **Events** (المسار `/event/booking_confirmed` …). بهذا تعرف:
كم زائراً → كم منهم ضغط واتساب → كم حجز فعلاً.

> إن كان موقعك على نطاق خاص مثل `stats.orasdentalclinic.com` (GoatCounter مستضاف ذاتياً)
> فاكتب الكود `stats` — الكود يُبنى تلقائياً على الشكل `CODE.goatcounter.com`.

---


**التغييرات لا تظهر فوراً؟** الموقع يستخدم كاش Sanity CDN لمدة ~60 ثانية.
اضغط **Publish** في اللوحة (وليس حفظ المسودة فقط) وانتظر دقيقة.
للتحديث الفوري اجعل `useCdn: false` في `index.html` (أبطأ قليلاً).

**الصور** تُحسَّن تلقائياً عبر Sanity CDN (`auto=format` + تحجيم مناسب)،
فارفع صوراً عالية الجودة دون قلق من حجم الصفحة.

**النشر:** أي تعديل على `index.html` يحتاج `git push` لتحديث الموقع.
أما تعديلات المحتوى من اللوحة فتظهر مباشرة بدون نشر.

## استكشاف الأخطاء

افتح **Console** في المتصفح (F12) — الموقع يطبع سبب المشكلة بوضوح.

| المشكلة | الحل |
|---|---|
| `HTTP 404` | `projectId` أو اسم الـ dataset خاطئ |
| `HTTP 403` | الـ dataset ليس Public (الخطوة 4) |
| خطأ CORS | أضف نطاقك في CORS origins (الخطوة 5) |
| `ℹ️ Sanity غير مفعّل` | `projectId` فارغ في `index.html` |
| المحتوى الافتراضي يظهر | لم تضغط **Publish**، أو الكاش لم ينتهِ بعد |
